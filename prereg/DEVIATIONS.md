# Deviations from the fixed settings

Every change to `study3_settings_2026-10-13.json` after 13 October 2026 is recorded here: date, what changed, why, and whether any demand data had been seen at the time. The original file is never edited; its SHA-256 fingerprint is in `README.md`. Each change also has a machine-readable file in `addenda/`, applied by the analysis code in file-name order.
