# Privacy Policy: CMKL Thesis Research

This project is a non-commercial undergraduate thesis at CMKL University, Bangkok, Thailand, supervised by Dr. Fawad Asadi. Contact: kwai@cmkl.ac.th.

## What data is used

The project reads public data through the YouTube Data API: video titles, publication dates, view, like and comment counts, and the text and dates of public comments. It does not access private data, user accounts or any data that requires a user's permission.

## What is not collected

Commenter names, channel names and channel IDs are discarded at collection and never stored. No data is collected from people who use this project, because it has no users.

## How data is used

Data is turned into aggregate measures, such as the number of videos and comments about a book before a given date, and used in statistical models for academic research. Results are published only as summary statistics.

## Storage and deletion

Data is stored privately on one encrypted computer and is not shared, sold or redistributed. Stored YouTube data is refreshed every 30 days until it is fixed for the final analysis, and anything no longer available on YouTube is deleted at that refresh. Raw YouTube data is deleted within 90 days of collection, once weekly aggregate measures have been computed; only those aggregate measures are kept. Data removed from YouTube is also removed from this project's data on request.

## YouTube Terms

This project uses YouTube API Services and follows the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

## Data handling law

Data is handled in line with Thailand's Personal Data Protection Act (PDPA).
